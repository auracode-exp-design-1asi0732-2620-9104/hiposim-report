# **Conclusions**

## **Conclusions and recommendations**

1. HipoSim permitió plantear una solución digital orientada a facilitar la simulación y comprensión de créditos hipotecarios para compradores de primera vivienda en el Perú, centralizando información financiera relevante en una plataforma accesible.

2. El análisis del problema y las necesidades del segmento objetivo permitió definir funcionalidades relacionadas con la simulación de cuotas, TCEA, cronogramas de amortización, comparación de escenarios y beneficios aplicables al financiamiento de vivienda.

3. La aplicación de Lean UX permitió orientar el diseño del producto a partir de las necesidades identificadas, estableciendo hipótesis y funcionalidades que pueden ser validadas progresivamente mediante la interacción de los usuarios con la solución.

4. La implementación de una arquitectura compuesta por frontend web, aplicación móvil y API RESTful permitió establecer una base tecnológica para integrar las funcionalidades del producto y facilitar su evolución y mantenimiento.

5. El uso de GitFlow, GitHub, Jira y Pull Requests permitió organizar el trabajo colaborativo, mantener la trazabilidad de los cambios y coordinar la integración de los diferentes componentes desarrollados por el equipo.

6. Como recomendación, se plantea continuar con la validación del producto mediante pruebas con usuarios, ampliar los escenarios de simulación financiera y mantener actualizados los parámetros y beneficios relacionados con el financiamiento de vivienda en el Perú.
